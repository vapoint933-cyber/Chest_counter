CHEST COUNTER - Android (Fortnite)

КАК ПОЛУЧИТЬ APK (бесплатно, без Android Studio, через GitHub):
 1. Зайди на github.com и зарегистрируйся (если нет аккаунта).
 2. Справа сверху "+" -> "New repository". Имя любое (например chest-counter). Public или Private - без разницы. Create repository.
 3. На странице репозитория нажми "uploading an existing file".
 4. Перетащи в окно ВСЁ СОДЕРЖИМОЕ этой папки (app, .github, build.gradle.kts, settings.gradle.kts, gradle.properties и т.д.).
    Важно: папка .github тоже должна загрузиться. Если не загрузилась: Add file -> Create new file,
    в имени напиши  .github/workflows/build.yml  и вставь туда текст из файла .github/workflows/build.yml.
 5. Внизу нажми "Commit changes".
 6. Открой вкладку "Actions". Запустится сборка "Build APK" (3-6 минут). Дождись зелёной галочки.
 7. Открой завершённый запуск -> внизу раздел "Artifacts" -> скачай "ChestCounter-apk" (zip), внутри app-debug.apk.
 8. Скинь apk на телефон и установи (разреши установку из неизвестных источников).

ВАРИАНТ B: Android Studio -> Open -> эту папку -> Build -> Build APK(s).

КАК ПОЛЬЗОВАТЬСЯ:
 1. Открой приложение -> "Разрешить поверх других приложений" -> включи переключатель.
 2. Нажми "Запустить" -> разреши запись экрана (выбери "Весь экран") - это нужно для автоподсчёта.
 3. Впиши, сколько сундуков уже открыто, и нажми "Сохранить число".
 4. Калибровка (один раз): нажми "Калибровка", открой Fortnite, открой сундук и нажми круглую кнопку 📷,
    пока на экране надпись "+600 ОП / СУНДУК". Обведи надпись пальцем и нажми "Сохранить".
 5. Всё. HUD висит поверх игры, нажатия проходят сквозь него. +1 / -1 / Стоп - в шторке уведомлений.
Размер и положение HUD, чувствительность - в приложении.
